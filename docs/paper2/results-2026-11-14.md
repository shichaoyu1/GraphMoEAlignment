# Idea2 实验结果与论证核查

整理日期 2026-11-14。Idea2 最早的 TopoMoE-GDI 将标签锚点家族混合专家与训练折共现图结合。图的节点是标签锚点，边来自训练患者的标签共现。新版修订矩阵聚焦家族条件评分、门控和监督来源。**旧版完整 MoE 方案提高了总体检索 mAP。新版共享投影的收益较小，独立投影降低总体 mAP，区域正例规则明显塑造门控。共现图先验的额外收益仍缺证据。**

## 1. 数据与统计口径

- 修订批次 70/70 次完成。14 组配置 × 5 折 × 初始化 seed 42，均记录提交 `7996161` 与同一份运行环境清单。每折训练、验证、测试为 375、125、125 人，测试折互斥，合计 625 人、1,875 个区域 query。每折 26 个标签原型，包括 20 个病理、6 个分子锚点。
- 旧主矩阵 45 次。3 种方法 × 5 折 × 初始化 seed 42、43、44。逐折核对了两批实验的训练、验证与测试患者、按列排列的锚点和 `region_rules` 测试正例。两批训练实现、目标函数与优化配方有差异。
- 从评分重算 AP、首个正例的倒数排名和首位命中。先在患者内平均三个区域，旧批次再在患者内平均三个初始化 seed，最后聚合患者。按患者配对重采样 10,000 次，报告百分位 95% 区间。区间未做多重比较校正，主要反映给定划分与已训练模型下的患者差异。新版只有 seed 42。
- 所有主表指标用完整候选库。`observed_fields` 使用已观测标签字段缩小候选范围，作为单独诊断。Grade 宏平均给 Grade 2、3、4 等权，整体指标纳入 Grade 未知的 7 人。所有指标为 0–1 刻度。

## 6. 逐条论证与修改范围

| 论证 | 建议写法及依据 |
|---|---|
| 区域 MRI 有用 | 在同一数据、同编码器结构下，区域 Direct 提高相对全局 ROI 的 mAP。相对节点频率的优势主要体现在 MRR，以及部分分级中的排序。 |
| 家族分解改善检索 | 旧版完整方案相对旧 Direct 有 +0.0773 mAP。新版共享动态提升 +0.0044，独立投影降低 mAP。可以区分家族内辨别与家族间分配，把结构的净收益留给冻结校准与跨 seed 复验。 |
| 个体动态门控必要 | 同条件重训练中 MRR 有小幅改善，两种投影下 mAP 增量的区间均含零。固定专家后，患者置换和验证集节点均值替换的损失远小于节点置换。 |
| 显式家族监督有效 | 区域规则下 mAP 改善、MRR 下降。患者全标签下未建立清晰 mAP 收益。监督与指标条件应随结论报告。 |
| 区域有特异的分子机制 | 区域正例改变后门控差异和置换损失显著收缩，标签完整子集亦然。独立区域分子或病理真值缺失，门控权重描述模型在给定任务中的行为。 |
| Graph 有额外性能价值 | 保留训练折共现先验与无结构 MoE 的对照。点估计接近，区间含零。边级发现或医学因果解释缺少独立验证。 |
| 跨机构泛化 | 现有 115 次运行来自同一队列。独立队列与相容标签定义仍待落实。 |

**数据限制。** 1,875 个区域 query 中有 352 个输入 mask 为空，占 18.8%。这些 query 仍在评估分母内。使用本机 UTSW 副本，按原始 T1 形状选分割、截取 7 个切片并缩放至 ROI 96，逐折复现的空 mask 数为 69、62、73、70、78。按区域合计为 Core 126、Edema 41、Enhancing 185。625 人实际选中的本机分割文件为 `rtumorseg_manual_correction.nii.gz` 362 例及 `tumorseg_FeTS.nii.gz` 263 例。服务器运行的 `segmentation_source` 为 `not_documented`，论文中仍需核对服务器分割清单及其生成来源，按空与非空输入报告结果。旧版路由收益随 Grade 分布变化，论文主表应同时保留节点频率、MRR、总体 mAP 与 Grade 宏平均。病理与分子标签均来自患者级元数据，未知项与明确阴性需要分别解释。当前数据属于已有分割条件下的 MRI 标签原型检索。

## 7. 笔记第 13 节替换文案

### 13.1 研究问题

在患者级标签不完整、区域 query 缺少独立组织学标注的情况下，用分割定义的 MRI 区域检索病理与分子标签原型。采用家族条件评分，将某个锚点的分数拆成家族门控与家族内评分。这个分解让我们分别检验家族间校准、家族内辨别和患者特异分配的影响。暂定题目可沿用 **Factorized Anchor Retrieval under Incomplete Patient-Level Supervision**。

### 13.2 性能与结构

70 次修订运行覆盖 625 名患者、五折和 seed 42。同协议下，节点标签频率达到 0.7378 mAP，Proxy Anchor 多标签适配为 0.7382，差值 +0.0004 的患者级 95% CI 跨零。节点频率的高总分与 Grade 4 占比有关。区域 Direct 的 mAP 相对全局 ROI 提高 0.0262，MRR 相对节点频率提高 0.0646。共享动态门控相对新版 Direct 的 mAP 增量为 0.0044，独立家族投影在相同动态门控下使 mAP 下降 0.0273。动态门控相对静态节点门控在 MRR 上有增量，mAP 优势尚待跨 seed 复验。固定专家时，用验证集的节点均值替代共享动态门控仅损失 0.0024 mAP。

### 13.3 监督规则与解释

在独立投影与动态门控下，将训练正例从区域规则改为患者全标签后，Edema−Enhancing 的分子权重差在开启显式家族监督时从 0.4958 降至 0.0119。171 名三项分子标签齐全的患者中，该差从 0.4657 降至 0.0203。在统一的区域测试正例下，节点置换的 mAP 损失从 0.0295 降到 0.0044。区域路由对监督规则敏感，依据当前数据能解释训练目标与模型行为的关系。区域生物学对应还需要独立标注。正文报告分割来源及 352 个空区域 mask，并按标签覆盖和 Grade 展示适用范围。

### 13.4 共现图的证据

旧版 TopoMoE-GDI 的锚点图由训练折的标签共现构建。旧五折三 seed 矩阵中，共现先验引导方案相对 Direct 提高 0.0773 mAP，相对无结构 MoE 的额外差值为 0.0006，95% CI [−0.0014, +0.0027]。保留图先验的设计与消融，图在现有数据中的增益作为开放问题。新版 70 次矩阵度量家族分解和监督条件，未加入锚点图。

### 13.5 下一步与论文主张
